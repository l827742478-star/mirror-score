# 镜面分数 · MIRROR SCORE

一个本地优先的颜值观察报告产品，复刻参考视频中“照片 → 分析 → 报告 → 建议”的机制和阅读节奏，使用原创品牌、文案、数据与视觉资源。

## 运行

```bash
python3 -m http.server 4183 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:4183>。

## 测试

```bash
npm test
node --check src/analysis.js
```

## 功能

- 支持 JPG、PNG、WEBP 图片，首页提供明确的“上传自己的照片”按钮，也保留一张原创真人风格台湾女性示例照
- 选择分析视角后，先通过 MediaPipe Face Landmarker 真实检测人脸关键点；无脸或多脸时会阻止生成报告
- 报告分数来自检测到的脸部比例、眼距、对称性、姿态，以及照片的光线和清晰度像素测量，不再使用文件名、文件大小或随机数猜分
- 报告包含总分、五维评分、风格定位、审美参照、四组五官拆解、妆容建议和配色建议
- 支持报告下载、海报预览、重新分析和 localStorage 恢复
- 支持移动端单列阅读、键盘焦点和打印布局

## 边界

报告由浏览器加载 MediaPipe Face Landmarker 后本地完成检测和测量，不上传照片；模型加载失败、未检测到人脸或检测到多张脸时不会生成报告。结果是基于图像几何和像素数据的观察性启发式指标，不是医学、审美或择偶判断，也不能替代专业咨询。示例照为生成的虚构成年女性形象，不对应任何特定真人。
