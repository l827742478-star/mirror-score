# 镜面分数 · MIRROR SCORE

一个本地优先的颜值观察报告产品，复刻参考视频中“照片 → 分析 → 报告 → 建议”的机制和阅读节奏，使用原创品牌、文案、数据与视觉资源。

## 运行

```bash
python3 -m http.server 4183 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:4183>。

## 测试

```bash
npm test
node --check src/analysis.js
```

## 功能

- 支持 JPG、PNG、WEBP 图片，首页提供明确的“上传自己的照片”按钮，也保留一张原创真人风格台湾女性示例照
- 选择分析视角后生成稳定的本地演示报告
- 报告包含总分、五维评分、风格定位、审美参照、四组五官拆解、妆容建议和配色建议
- 支持报告下载、海报预览、重新分析和 localStorage 恢复
- 支持移动端单列阅读、键盘焦点和打印布局

## 边界

报告由浏览器中的确定性演示算法生成，不调用人脸识别服务，不上传照片，也不构成医学、审美或择偶判断。示例照为生成的虚构成年女性形象，不对应任何特定真人。
